# docs/

이 폴더는 코드와 함께 버전 관리되는 **in-repo 최신 설계 문서 사본**이다(STEP 03 지시사항 5번 폴더 구조 요구사항).

## 이 폴더와 `작업파일/`(프로젝트 루트) 및 Claude Project의 관계

- **Claude Project(claude.ai)**: 원본이자 최신 상태. 세션이 문서를 수정할 때마다 여기가 먼저 갱신된다.
- **`작업파일/`(이 저장소 루트, `docs/`의 상위 폴더)**: 사용자가 이전에 직접 다운로드해 저장해 둔 7개 문서(ARCHITECTURE/DATABASE/API/SECURITY/I18N/AI_RESEARCH/QA)의 스냅샷. STEP 03 이전 버전이라 이후 갱신 내용(D5/D24 ACCEPTED 반영 등)이 빠져 있다. **삭제하지 않았다** — 절대 원칙(기존 파일 임의 삭제 금지)에 따름.
- **`docs/`(여기)**: STEP 03 시점 기준 최신 사본. `DECISIONS.md`, `STEP03_PRE_AUDIT.md`도 포함되어 있어 `작업파일/`보다 최신이다.

**중복이 존재한다는 점을 알려드립니다** — 어느 쪽을 정본으로 유지할지(`작업파일/` 삭제, `docs/`만 유지 등)는 사용자가 결정할 사항이며, 이 세션이 임의로 정리하지 않았다.

## 이후 계획

앞으로 문서가 갱신될 때마다 Claude Project + 이 `docs/` 폴더 양쪽에 반영한다. 새로운 설계 결정 문서(ADR 등)도 이 폴더에 추가될 수 있다.
