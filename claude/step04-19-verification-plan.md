## 0. 검증 환경

| 단계 | 환경 | 확인 가능한 것 |
|---|---|---|
| A | 웹 미리보기 (`npx expo start --web --clear`) | 광고, 신고, 거래완료, 콘텐츠 번역, 알림 수신함 |

## A. 웹에서 확인

### A-1. 광고 (돈이 오가는 부분 — 가장 먼저)

- [ ] 관리자 → `MY > 정산관리` → 추천/TOP10 **최소 클릭 광고비** 설정
- [ ] 업체 → 충전 신청(**100,000 미만은 거부되어야 함**)
- [ ] 관리자 → 승인하며 **실입금액**을 직접 입력 → 업체 잔액이 그 금액으로 반영
- [ ] 업체 → `MY > 유료 노출광고` → 추천매물 선택 → 매물 선택 → 순위 진입 → 저장
- [ ] 홈 "최근 TOP10" / 추천 캐러셀에 노출
- [ ] **부동산 탭 추천 캐러셀**에도 같은 매물 — 09-12 수정분
- [ ] 매물 클릭 → 잔액 차감
- [ ] **1시간 안에 다시 클릭 → 차감되지 않음**
- [ ] 잔액 소진 → 자리에서 빠지고 아래 순위가 올라옴
- [ ] 다른 업체가 더 높은 금액으로 진입 → 밀려난 매물이 자리에서 삭제
- [ ] 순위 인하 → 주황색 경고 후 실제로 내려감
- [ ] 거래완료 처리 → 광고 자리 자동 반납 + 고객 화면에서 사라짐
- [ ] **거래완료 매물이 유료 노출광고 목록에 보이지 않음** — 09-12 수정분

### A-2. 허위매물 신고

- [ ] 매물 상세 우측 하단 신고 버튼 → 팝업 → 접수
- [ ] 같은 계정으로 재신고 → "이미 신고한 매물입니다"
- [ ] 다른 계정으로 신고 → 접수되고 건수 증가
- [ ] 관리자 `MY > 허위매물 신고` → 매물 단위로 묶여 건수 표시
- [ ] 처리완료 → 상태 배지 변경

### A-3. 콘텐츠 번역 (신규)

- [ ] 매물 등록 또는 수정 → 설명 입력 → 저장 — **수 초 걸림**(5개 언어 번역)
- [ ] 매물 상세에서 설명 확인
- [ ] 언어를 English로 변경 → **같은 매물 설명이 영어로** ← 핵심
- [ ] 투자상품도 동일하게
- [ ] **설명은 그대로 두고 가격만 수정 → 저장이 즉시 끝남**(재번역 생략 확인)
- [ ] 예전에 등록한 매물 → 언어를 바꿔도 원문 그대로(의도된 동작)

### A-4. 알림 수신함 (신규)

- [ ] `MY > 설정 > 알림` → 수신함 진입(예전엔 "준비 중" 토스트)
- [ ] 관리자가 충전 승인 → **신청자 계정**의 수신함에 알림, MY 알림 줄에 숫자
- [ ] 알림 누름 → 읽음 처리 + 해당 화면으로 이동
- [ ] 전체 읽음 / 개별 삭제
- [ ] 우측 상단 설정 아이콘 → 8종 토글
- [ ] **끈 종류의 알림은 수신함에도 쌓이지 않음**
- [ ] 업체 승인/반려, QA 답변, 신고 처리도 각각 알림 생성

### A-5. RLS

- [ ] 로그아웃 상태에서 앱을 훑어 **콘솔 오류가 늘지 않았는지** 확인
      (payment_settings / agency_permissions를 비로그인에서 못 읽게 바꿨다 —
      비로그인 화면이 그 값을 쓰고 있었다면 여기서 드러난다)
